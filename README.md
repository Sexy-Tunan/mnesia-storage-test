# Mnesia 最大存储容量测试

本项目用于测试 Mnesia 在不同存储模式下的**最大存储容量**，对比以下两种模式：
- **disc_copies 模式**：数据同时存储在磁盘和内存中
- **disc_only_copies 模式**：数据仅存储在磁盘上

通过不断插入大数据（每条记录约1MB）来测试每种模式能够存储的最大数据量，以及在达到存储极限时的表现。

## 存储模式说明

### disc_copies 模式
{disc_copies, Nodelist},其中 Nodelist 是一个列表，它列出了应该具有 disc_copies 的节点。
如果一个表副本的类型是 disc_copies，那么对该表特定副本的所有写操作都会写入 disc，并写入表的 RAM 副本(创建表的节点会有一个RAM内存副本，并不是所有节点都有)。
可以在一个节点上有一个 disc_copies 类型的复制表，而在另一个节点上有另一种类型的复制表。默认值是[]

### disc_only_copies 模式
{disc_only_copies, Nodelist},其中 Nodelist 是一个列表，列出了该表应该具有 disc_only_copies 的节点。
一个disc_only 表副本只保留在 disc 上，与其它副本类型不同，副本的内容不驻留在 RAM 中。
这些副本比驻留在RAM中的副本慢得多。


## 预期结果

### disc_copies 模式
- **优点**：读写速度快
- **缺点**：内存占用大，受限于可用内存
- **预期极限**：取决于系统内存，每条1MB记录，假设有8GB可用内存，约能存储 8,000 条记录

### disc_only_copies 模式
- **优点**：内存占用小，主要占用磁盘空间
- **缺点**：读写速度慢
- **预期极限**：取决于磁盘空间，假设有100GB可用磁盘，约能存储 100,000 条记录
